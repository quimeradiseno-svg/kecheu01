# Kecheu

Landing editorial de una página, construida con Sites/Vinext y React.

- `npm run dev`: vista local.
- `npm run build`: versión de producción.
- `npm exec tsc -- --noEmit`: comprobación de tipos.
- `app/content.ts`: fotos reemplazables, galerías y contactos.
- `design-references/REEMPLAZOS.md`: tomas pendientes y transparencia.
- `design-references/image-manifest.json`: trazabilidad de cada imagen.

Interacciones: profundidad sutil con mouse, progresión de scroll, transición de la obra a la casa, galerías con arrastre/teclado, manifiesto reactivo y pausa de movimiento. Respeta movimiento reducido del sistema.

Las cabañas 01 y 02 alojan cuatro personas cada una y están adosadas en espejo. Sus fotos exteriores son compartidas; las galerías interiores respetan las carpetas confirmadas. La tercera es para dos.

Mantener privada la versión de revisión hasta confirmar contactos y permisos. No hay reservas, almacenamiento de datos personales ni mensajes enviados automáticamente.
